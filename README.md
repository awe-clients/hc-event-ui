# Corrida do Empreendedor 2026 — Protótipo HTML v8

Arquitetura refatorada conforme o novo alinhamento de UX:

- Home: vitrine máxima do evento.
- Páginas principais: `corrida.html`, `palestras.html`, `expo.html` com `Primary Page Hero`.
- Páginas de suporte: `programacao.html`, `kit.html`, `local.html`, `faq.html`, `noticias.html` com cabeçalho reduzido.
- Detalhes contextuais: provas, palestra, palestrante e experiências da Expo preservam continuidade com a página pai.
- Texto de leitura: 16px mínimo; 18px como baseline editorial.
- CTA: saliência proporcional ao estágio da jornada.
- Uma única folha `tailwind.css` e um único `site.js`.
- Phosphor Icons Regular.

Arquivos de detalhe da Expo: `hospitalidade.html`, `feito-potiguar.html`, `gastronomia.html`, `experiencias-de-marca.html`.

Este protótipo é a base visual para posterior modelagem em WordPress/Gutenberg + CPTs.
